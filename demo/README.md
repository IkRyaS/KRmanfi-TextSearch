# Демо-набор

Все файлы синтетические, созданы скриптом `scripts/make_demo.py`, личных данных нет.
Главная фраза — **`квартальный отчёт`** (без учёта регистра, «е» = «ё»).

В программе: «Папка…» → выберите эту папку `demo` → «Текст» → `квартальный отчёт` → «Найти».
Ожидается строка итога (с включённым OCR; сканы занимают 15–30 секунд, зависит от числа ядер):

```
найдено 27 фрагментов в 17 файлах; просмотрено 24 файлов; без текста — 1; ошибок — 3
```

Этот файл тоже лежит в папке `demo`, поэтому он тоже находится (в нём фраза встречается в
описании). Остальные файлы:

| Файл | Что показывает | Результат |
|---|---|---|
| `документы/01_текстовый_слой.pdf` | PDF с текстом | `стр. 2` |
| `документы/03_повторы_на_странице.pdf` | несколько вхождений на одной странице | раскрывающаяся группа «стр. 1», 3 вхождения |
| `документы/04_протокол.docx` | абзацы и таблица | `абзацы 1–5`, 3 вхождения |
| `документы/05_платежи.xlsx` | два листа | `лист «Платежи»`, `лист «Заметки»` |
| `документы/06_презентация.pptx` | слайд и заметки | `слайд 1`, 2 вхождения |
| `документы/07_заметки.txt` | регистр | «Квартальный Отчёт» |
| `документы/08_журнал_работы.txt` | строки | `строки 1–3` |
| `документы/09_данные.csv` | кодировка CP1251 | `строки 1–3` |

Что ещё показать на защите: кнопка **Стоп** во время поиска по сканам; неверное регулярное
выражение `(`; фильтр результатов; экспорт в CSV; двойной щелчок по результату из вложенного ZIP.
