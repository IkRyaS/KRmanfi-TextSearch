# KRmanfi Text Search

Настольное приложение для поиска текста в документах: PDF (в том числе **сканы и фото страниц** —
через OCR), DOCX, XLSX, PPTX, TXT/MD/LOG/CSV и **ZIP-архивы** (в том числе вложенные).
Работает полностью офлайн в Windows и Linux. Результаты появляются по мере поиска,
у каждого совпадения видны файл, страница или лист и контекст; двойной щелчок открывает файл.

> Зачем: нужная фраза, номер договора или ИНН лежит где-то среди сотен PDF, Word, Excel,
> сканов и архивов. Поиск ОС не заглядывает в сканы и архивы — это приложение заглядывает.

## Запуск за 3 шага

### Windows 10/11 (готовая сборка)
1. Распакуйте `KRmanfi-TextSearch-win64.zip`.
2. Дважды щёлкните `KRmanfiSearch.exe` (или `run.bat`).
3. Нажмите «Папка…», выберите папку `demo`, введите `квартальный отчёт`, нажмите «Найти».

Tesseract (языки `rus`, `eng`, `osd`) уже внутри архива — ставить ничего не нужно.

### Linux (готовая сборка, Ubuntu 22.04+)
```bash
tar -xzf KRmanfi-TextSearch-linux-x64.tar.gz
cd KRmanfi-TextSearch
./setup_linux.sh      # проверит системные библиотеки и напечатает команду apt, если чего-то нет
./run.sh
```
Tesseract встроен в архив. Для окна Qt на Linux нужна библиотека `libxcb-cursor0`
(`sudo apt install libxcb-cursor0`); `setup_linux.sh` скажет, если её нет.

### Из исходников (Windows и Linux)
Нужен Python 3.13 и, для сканов, программа Tesseract с языками `rus` и `eng`.

```bash
python -m venv .venv
# Windows (PowerShell): .venv\Scripts\Activate.ps1      Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
pip install --no-deps -e .
python -m krmanfi_search
```
Tesseract: Windows — `winget install UB-Mannheim.TesseractOCR` (русский язык выберите при
установке или положите `rus.traineddata` в `tessdata`); Linux — `sudo apt install tesseract-ocr tesseract-ocr-rus`.
Без Tesseract приложение запускается и ищет в обычных документах, а сканы попадают в «файлы без текста».

Системные требования: 64-разрядная ОС, ≥ 4 ГБ ОЗУ, около 500 МБ на диске.

## Как пользоваться

1. **Где** — папка или один архив/файл. **Текст** — что искать.
2. Режим: *Подстрока* (без учёта регистра, «е» = «ё») или *Регулярное выражение*.
3. Флажки: учитывать регистр; сколько символов контекста показывать; **OCR сканов PDF**;
   **искать в архивах**.
4. **Найти** — результаты идут в дерево «файл → страница → вхождения». Страница с несколькими
   вхождениями раскрывается группой. **Стоп** (или Esc) останавливает поиск.
5. Строка «Фильтр результатов» сужает список. **Экспорт (CSV)** сохраняет только видимые строки.
6. Двойной щелчок по строке открывает файл программой по умолчанию (файл из архива — из
   временной копии, она удаляется при закрытии окна).
7. По окончании: «найдено N фрагментов в M файлах; просмотрено K файлов; без текста — X;
   ошибок — Y» и кнопка **«Файлы без текста / ошибки…»**.

Демо-набор и ожидаемые результаты — в [`demo/README.md`](demo/README.md).

## Форматы и место совпадения

| Формат | Чем читаем | Место |
|---|---|---|
| PDF с текстовым слоем | PyMuPDF | `стр. N` |
| PDF-скан или фото страницы | PyMuPDF + OpenCV + Tesseract `rus+eng` | `стр. N (OCR)` |
| DOCX | python-docx | `абзацы A–B`, `колонтитулы` |
| XLSX | openpyxl | `лист «Имя»` |
| PPTX | python-pptx | `слайд N` (включая заметки) |
| TXT, MD, LOG, CSV | кодировка определяется автоматически (UTF-8, CP1251) | `строки A–B` |
| ZIP, в том числе вложенные (до 3 уровней) | zipfile | `архив.zip!/папка/файл.pdf` |

## Что происходит при ошибках

| Ситуация | Поведение |
|---|---|
| Пустой запрос | кнопка «Найти» неактивна |
| Неверное регулярное выражение | сообщение под строкой состояния, приложение работает дальше |
| Папки нет или нет доступа | понятное сообщение, поиск не стартует |
| Зашифрованный или битый PDF/DOCX | файл в «ошибки», остальные обрабатываются |
| Битый ZIP, `../` в имени, zip-бомба | запись в «ошибки», в файловую систему ничего не пишется за пределами временной папки |
| Нет Tesseract | жёлтое предупреждение; сканы попадают в «без текста» |
| Файл больше 200 МБ | пропускается и показывается в списке «пропущено» |
| Ничего не найдено | «совпадений нет» и статистика |
| Стоп или закрытие окна | рабочие процессы завершаются, временные папки удаляются |
| Повторный поиск | прежние результаты не смешиваются с новыми |

## Данные и настройки

* Журнал: `%APPDATA%\KRmanfiSearch\logs\krmanfi-search.log` (Windows),
  `~/.local/share/KRmanfiSearch/logs/` (Linux).
* Никакого кэша и индекса на диск не пишется; временные файлы — в системной папке `krmanfi-search-*`
  и удаляются по окончании.
* `settings.toml` рядом с программой (необязателен): процессы, контекст, лимит размера, языки OCR,
  путь к `tesseract`. Копия в папке данных пользователя имеет приоритет.
* Приложение не обращается к сети.
