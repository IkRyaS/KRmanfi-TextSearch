# Поиск по документам

Небольшая программа для Windows и Linux: вводите слово — она находит его в **PDF** (в том числе
в сканах и фото страниц), **Word**, **Excel**, **PowerPoint**, текстовых файлах и **ZIP-архивах**
(даже вложенных). Работает без интернета. Результаты появляются по ходу поиска.

> Зачем: нужный договор, номер или ИНН лежит где-то среди сотен файлов. Поиск операционной
> системы не заглядывает в сканы и архивы — эта программа заглядывает.

## Как пользоваться

1. **Где искать** — нажмите «Выбрать…» (или перетащите папку в окно).
2. **Что искать** — введите слово и нажмите «Найти» (или Enter). «Стоп» — Esc.
3. Результаты: файл → страница → совпадения. Двойной щелчок по результату в PDF открывает
   **картинку этой страницы с подсвеченными совпадениями** (подсвечиваются все слова на странице,
   в том числе на сканах и в PDF из архива); в окне можно приблизить страницу или нажать «Открыть
   файл целиком». Остальные форматы (Word, Excel, PowerPoint, текст) открываются программой по умолчанию.
4. «Сузить список» фильтрует результаты, «Сохранить в CSV» записывает то, что видно на экране.

Галочки: *Учитывать регистр*, *Регулярное выражение*, *Распознавать сканы* (OCR), *Искать в ZIP*.
Без регулярного выражения «е» и «ё» считаются одной буквой, регистр не важен.

Попробуйте на демо-наборе: папка `demo`, фраза `квартальный отчёт` (подробности — `demo/README.md`).

## Запуск готовой сборки

* **Windows 10/11:** распакуйте `KRmanfi-Search-win64.zip` и откройте `KRmanfiSearch.exe`.
* **Linux (Ubuntu 22.04+):**
  ```bash
  tar -xzf KRmanfi-Search-linux-x64.tar.gz
  cd KRmanfi-Search
  ./setup_linux.sh   # проверит библиотеки и напечатает команду apt, если чего-то не хватает
  ./KRmanfiSearch
  ```

Распознавание сканов (Tesseract, языки rus и eng) уже внутри сборки.

## Запуск из исходников и сборка — только через uv

Установите [uv](https://docs.astral.sh/uv/) (он сам скачает нужный Python 3.13 и библиотеки):

| ОС | Команда установки |
|---|---|
| Windows | `winget install --id astral-sh.uv -e` |
| Linux | `curl -LsSf https://astral.sh/uv/install.sh \| sh` |

**Запуск без сборки:**

```bash
uv run krmanfi-search        # или scripts\run.bat / scripts/run.sh
```

Для распознавания сканов в этом режиме нужен Tesseract: Windows —
`winget install UB-Mannheim.TesseractOCR` (установщик кладёт только английский: файл
`rus.traineddata` из [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast) нужно добавить в
папку `tessdata` рядом с `tesseract.exe`, иначе русские сканы читаются неверно; тесты OCR без
русского языка пропускаются); Linux —
`sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng`.

**Сборка:**

| ОС | Что запустить | Результат |
|---|---|---|
| Windows | двойной щелчок по `scripts\build_windows.bat` | `dist\KRmanfi-Search-win64.zip` (внутри `KRmanfiSearch.exe`) |
| Linux | `bash scripts/build_linux.sh` | `dist/KRmanfi-Search-linux-x64.tar.gz` (внутри `KRmanfiSearch`) |

Собирать нужно на той ОС, для которой нужен файл. Скрипт сам создаёт окружение, запускает
PyInstaller, встраивает Tesseract (если он установлен на машине сборки — в Windows скрипт
попробует поставить его через winget) и пакует архив. Рядом лежит `SHA256SUMS.txt`.

**Проверки (по желанию):**

```bash
uv run --extra dev ruff check src tests scripts
uv run --extra dev pytest
```

## Если что-то пошло не так

| Ситуация | Что будет |
|---|---|
| Пустой запрос или путь | кнопка «Найти» неактивна |
| Неверное регулярное выражение | сообщение под строкой состояния, программа работает дальше |
| Папки нет или нет доступа | понятное сообщение, поиск не стартует |
| Зашифрованный или битый PDF/DOCX/ZIP | файл попадает в «Файлы без текста и ошибки», остальные ищутся дальше |
| ZIP с `../` в именах и zip-бомба | запись отклоняется, за пределы временной папки ничего не пишется |
| Нет Tesseract | жёлтое предупреждение; сканы попадают в «без текста» |
| Файл больше 200 МБ | пропускается и попадает в список |
| «Стоп» или закрытие окна | процессы останавливаются, временные файлы удаляются |

## Данные и настройки

* Журнал: `%APPDATA%\KRmanfiSearch\logs\` (Windows), `~/.local/share/KRmanfiSearch/logs/` (Linux).
* Кэш и индекс на диск не пишутся; временные файлы лежат в `krmanfi-search-*` и удаляются.
* `settings.toml` рядом с программой (необязателен): число процессов, контекст, лимит размера,
  языки OCR, путь к `tesseract`.
* Сеть не используется.

## Устройство

```
presentation/   окно (PySide6), тема в оттенках бирюзового, модель дерева результатов
application/    сценарий SearchText
infrastructure/ обход папок, извлечение текста, ZIP, OCR (Tesseract + OpenCV), CSV
domain/         SearchQuery, SearchHit, SearchStats
container.py    ручное связывание зависимостей
```
